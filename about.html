About This Project

This project is a demo webpage showcasing Airbnb listings in San Francisco. It is built using HTML, CSS, and Bootstrap for styling and layout. The page includes a header with navigation links, a main section with information about the project, and a footer with credits.

The data for the Airbnb listings is sourced from a public dataset and is displayed in a user-friendly format. The design is clean and modern, with a focus on usability and accessibility.
